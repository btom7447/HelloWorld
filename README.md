# Overview

This project strengthens my ability to create, explain, and publish a small software solution using JavaScript and Node.js.

This beginner-friendly application prints "Hello World!" and a personalized greeting to the terminal. It demonstrates how to define and call a function.

I created this software to practice the basic workflow of writing, running, documenting, and publishing a program.

[Software Demo Video](https://youtu.be/zgoGlax_ZcM)

[GitHub Repository](https://github.com/btom7447/HelloWorld)

# Development Environment

I used Visual Studio Code and Node.js 24.21.0 to develop and test this software.

The programming language used is JavaScript. Node.js runs the JavaScript file from the terminal, and this project does not require third-party dependencies.

To run the application, open a terminal in the project folder and enter:

```bash
node hello.js
```

The expected output is:

```text
Hello World!
Welcome, Benjamin John Tom, to JavaScript with Node.js.
```
